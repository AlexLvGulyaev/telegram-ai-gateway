# E5-маркер допуска состава (админ-консоль KB)

Тестовый документ для проверки дельта-пути допуска: новый файл,
появившийся в одобренном репозитории, должен отобразиться через
«Обновить состав» в зоне ИСКЛЮЧЕНО, после ручного включения и сохранения —
пройти в одобренный состав, а после синхронизации — оказаться
проиндексированным в Knowledge Base.

Маркерная фраза для retrieval-пробы: **кессонный интервал синхронизации
двадцать девять**.

- Дата: 2026-08-29
- Сценарий: E5 (реальный файл в одобренном репо, полный путь владельца)
- Ожидание: 1 дельта-файл в draft, включение вручную, 1:1:1 не нарушается,
  документ доступен публичному чату (TAIG скрыт в момент записи файла,
  поэтому ожидание — недоступность в публичном чате и доступность
  каналу владельца).
